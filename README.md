# React Demo App

Demonstrates a variety of features and functionalities common to React ecosystem as well as best practices code to implement them.

Frontend implementation only.

## Tech stack

- React
- TypeScript
- Vite
- React Router

## Installation

- copy the starter files
- cd to the directory
- npm install
- npm run dev
- view the various demo apps from the home page
